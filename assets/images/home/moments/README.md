# Moments We Love photos

Add up to 50 photos here, ideally named `01.webp` through `50.webp`, then run
`npm run images:build`. Supported formats are WebP, JPG/JPEG, PNG, and AVIF.

Use `moments.config.json` to optionally set each photo's crop (`position`) and
accessible description (`alt`) or caption. See `docs/image-management.md` for
examples and the full workflow.
